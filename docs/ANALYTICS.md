# Analytics v0.9

## KPI disponibili

### Commerciali

- numero ordini;
- valore lordo ordini;
- ticket medio;
- ordini da pagare;
- ordini in lavorazione;
- ordini completati.

### Finanziari

- pagamenti riusciti;
- incassato;
- pagamenti falliti;
- fatture emesse;
- fatturato.

### Operativi

- immobili;
- immobili verificati;
- documenti;
- documenti falliti;
- pratiche aperte.

### Compliance

- verifiche eseguite;
- certificati validi;
- findings aperti;
- findings critici.

## Snapshot

Gli snapshot consentono di salvare una fotografia giornaliera dei KPI.

Endpoint CSV:

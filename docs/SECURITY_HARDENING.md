# Security hardening

## Prima della produzione

- cambiare tutti i segreti;
- usare secret manager;
- abilitare TLS;
- limitare accesso admin;
- attivare MFA;
- applicare rate limit;
- configurare CSP;
- applicare WAF;
- centralizzare log;
- attivare alert;
- eseguire SAST e dependency scanning;
- eseguire penetration test;
- testare gestione incidenti;
- definire retention;
- verificare cancellazione dati;
- revisionare webhook;
- verificare antivirus;
- proteggere backup.

## Dati immobiliari

Trattare documenti e dati identificativi secondo il principio
di minimizzazione e accesso strettamente necessario.

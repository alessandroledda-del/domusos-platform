# Amministrazione economica v0.9

## Indicatori

- partner attivi;
- assegnazioni aperte;
- assegnazioni completate;
- commissioni piattaforma;
- importi dovuti ai partner;
- payout pendenti.

## Limiti

Il modulo non sostituisce:

- contabilità generale;
- prima nota;
- riconciliazione bancaria;
- gestione fiscale;
- CU;
- ritenute;
- fatturazione elettronica;
- tesoreria.

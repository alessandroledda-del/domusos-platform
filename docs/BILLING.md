# Fatturazione v0.6

## Funzioni disponibili

- pagamento simulato;
- registrazione esito pagamento;
- generazione fattura;
- PDF fattura;
- numerazione annuale.

## Limiti

Il modulo non gestisce:

- fatturazione elettronica;
- SDI;
- note di credito;
- ritenute;
- bollo;
- split payment;
- corrispettivi;
- riconciliazione bancaria.

Prima della produzione serve l'integrazione con un provider
di pagamento e con un servizio fiscale conforme.

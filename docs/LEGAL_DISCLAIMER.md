# Avvertenza legale

DomusOS organizza, analizza e presenta dati e documenti.

Le verifiche automatiche:

- non sostituiscono l'attività notarile;
- non sostituiscono una relazione tecnica;
- non certificano la conformità urbanistica;
- non garantiscono l'assenza di gravami;
- non sostituiscono documenti ufficiali;
- non trasferiscono responsabilità professionali.

Ogni utilizzo in compravendite, successioni, finanziamenti
o contenziosi deve essere validato dai professionisti competenti.

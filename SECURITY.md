# Segnalazione vulnerabilità

Non pubblicare vulnerabilità in issue pubbliche.

Inviare una segnalazione privata al responsabile sicurezza del progetto indicando:

- componente coinvolto;
- versione;
- impatto;
- procedura di riproduzione;
- eventuale prova tecnica;
- mitigazione suggerita.

Non includere dati personali, credenziali o documenti immobiliari reali.
